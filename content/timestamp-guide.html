时间戳转换完全指南：从概念到实战

发布日期：2026-05-12

广告位

时间戳（Timestamp）是计算机中表示时间的一种方式，通常指从1970年1月1日0时0分0秒（UTC）到现在的总秒数。几乎所有编程语言和数据库都使用时间戳来存储时间，因为它是一个整数，不涉及时区问题。

为什么需要时间戳转换？

时间戳是一串数字（如1715678900），人类无法直接读懂。当你看到API返回的创建时间是一串数字时，就需要转换成可读的日期格式。反之，有时你需要把"2026年5月18日"存到数据库，也需要转成时间戳。

JavaScript中的时间戳转换

// 获取当前时间戳（毫秒）
const ts = Date.now()  // 1715678900000
// 转为秒
const tsSec = Math.floor(Date.now() / 1000)

// 时间戳 → 日期
const date = new Date(1715678900 * 1000)
console.log(date.toLocaleString('zh-CN')) // 2026/5/14 15:15:00

// 日期 → 时间戳
const ts2 = Math.floor(new Date('2026-05-14').getTime() / 1000)

Python中的时间戳转换

import time, datetime
# 当前时间戳
ts = int(time.time())
# 时间戳 → 日期
dt = datetime.datetime.fromtimestamp(ts)
# 日期 → 时间戳
ts2 = int(datetime.datetime(2026,5,14).timestamp())
